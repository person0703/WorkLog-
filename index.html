모둠로그 — 보이지 않는 일 기록기

모둠 과제에서 자료 조사나 PPT 제작 같은 주요 업무뿐 아니라 출처 정리, 오탈자 검토, 형식 통일 같은 보조 업무가 누구에게 얼마나 배분됐는지 한눈에 확인합니다.

작업 개수가 같아도 실제 사용한 시간은 다를 수 있습니다. 이 도구는 사람의 성실도나 능력을 평가하기 위한 것이 아니라, 기록된 사실과 수치를 바탕으로 앞으로의 역할 분담을 함께 조정하기 위해 만들었습니다.

사용 방법
  1. 모둠원 등록: 모둠원 이름을 먼저 추가합니다.
  2. 작업 기록: 주요 업무와 보조 업무를 나누어 예상·실제 시간을 적습니다.
  3. 목록 점검: 담당자, 종류, 상태별로 작업을 필터링해 확인합니다.
  4. 역할 조정: 그래프와 표로 실제 시간 차이를 보고 다음 역할을 조율합니다.

한 기기 저장 안내

모든 기록은 현재 사용 중인 같은 브라우저(localStorage)에 자동 저장되며 새로고침 후에도 유지됩니다. 별도 로그인이나 서버 저장이 없으므로 다른 기기와 자동으로 동기화되지 않습니다.

01. 모둠원 관리

모둠원 이름을 수정해도 고유 번호(ID)로 연결되어 기존 작업 기록이 그대로 유지됩니다.

등록된 모둠원 0명

02. 작업 등록

주요 업무와 보조 업무를 구분하여 기록하면 보이지 않던 준비·정리 시간까지 정확히 파악할 수 있습니다.

시간 기록 안내

실제 시간에는 수정에 사용한 시간도 포함해 주세요.

같은 시간을 주요 업무와 보조 업무에 중복 기록하지 마세요.

예: 보고서 작성 60분 중 오탈자 검토가 10분이었다면 보고서 작성 50분, 오탈자 검토 10분으로 나누어 기록합니다.

작업을 등록하려면 먼저 위 01. 모둠원 관리에서 모둠원을 1명 이상 추가해 주세요.
업무 구분 및 선택 *
업무를 선택하면 해당 업무의 설명이 여기에 표시됩니다.
직접 입력 업무 종류 *
기본 업무 목록에 없는 작업을 기록할 때 사용합니다. 아래 작업명 입력란에 이름을 직접 적어 주세요.

예: '자료 조사 — 2장 통계 부분'처럼 구체적으로 적거나 비워둘 수 있습니다.

빈칸은 '미입력', 0 입력은 '0분'으로 구분됩니다.

전체 작업 기준

위 작업 목록의 필터 선택과 관계없이 등록된 전체 작업을 기준으로 합계와 비율을 계산합니다.

입력된 기록 기준입니다. 작업 시간만으로 기여 전체를 판단할 수 없습니다.
